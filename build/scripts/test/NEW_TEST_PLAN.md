# ZyWeb前端功能测试计划

## 测试目标
验证ZyWeb前端应用的各个功能模块是否能正常加载和运行

## 测试环境
- 服务器地址: http://127.0.0.1:8819
- 测试框架: Zombie.js
- 测试工具: Node.js

## 测试用例

### 1. 首页测试
- [ ] 验证首页能否正常访问
- [ ] 验证页面标题是否正确
- [ ] 验证#app元素是否存在
- [ ] 验证JavaScript是否正常加载

### 2. 导航功能测试
- [ ] 验证导航栏是否正常显示
- [ ] 验证各个导航链接是否可点击
- [ ] 验证页面切换功能是否正常

### 3. 各模块页面测试
- [ ] Film模块页面加载测试
- [ ] IPTV模块页面加载测试
- [ ] Drive模块页面加载测试
- [ ] Lab模块页面加载测试
- [ ] Setting模块页面加载测试

### 4. API接口测试
- [ ] 健康检查接口测试 (/api/health)
- [ ] 设置接口测试 (/api/v1/setting/*)
- [ ] 用户接口测试 (/api/v1/users/*)

## 测试执行步骤
1. 启动ZyWeb服务器
2. 运行Zombie.js测试脚本
